# Consulting Practice

PartyGem AI is a consulting agency. Alongside our product work on the Gems family, we take on outside engagements — and we treat them with the same seriousness we apply to PartyGem itself.

## What we offer

### AI/ML
- Applied machine learning for classification, ranking, search, and personalization.
- **RAG systems** grounded on client data (we've built production RAG over event content with Pinecone).
- **Agentic workflows** with deterministic guardrails — the LLM plans; Go + SQL own the ledger.
- Model evals, prompt hardening, and safety rails.
- **MLOps** — productionizing, monitoring, and iterating ML systems on cloud infrastructure.

### Full-stack software
- **Backends:** Go, Python, Node/TypeScript. Postgres, MySQL, Redis. Server-authoritative trust boundaries by default.
- **Frontends:** Next.js, React, HTMX (we're HTMX-friendly and SSR-first when it fits). Tailwind + shadcn/ui.
- **APIs:** REST, WebSockets, HTMX endpoints; typed contracts where it matters.
- **Cloud:** AWS-first (EC2, RDS, CloudWatch, Secrets Manager). Docker Compose for local dev.

### Payments & commerce
- **Stripe** and **Stripe Connect** — subscriptions, marketplaces, webhook hardening, Connect account onboarding, refund rules, dispute flows.
- Auditable money flows and reconciliation patterns.

### Compliance-friendly engineering
- AuthN/Z design (tier + org RBAC composition).
- Privacy-by-default data models.
- Observability on a budget (Prometheus + Grafana self-hosted, or CloudWatch) before committing to paid SaaS.

## How we scope

We prefer **deeply-scoped engagements** over open-ended hourly contracts. A typical scope:

1. **Discovery (fixed-fee, 1–2 weeks).** We read the code, interview the team, and ship a written plan with architecture, tradeoffs, and a cost range.
2. **Build phase (milestone-based).** Two- to six-week sprints with clear deliverables; demo at each milestone.
3. **Hardening & handoff.** Runbooks, tests, documentation, and knowledge transfer. We want the client team self-sufficient.

We're happy to team with existing engineering orgs, not replace them.

## When we say yes

- You need AI/ML shipped to production and you don't want a research-mode vendor.
- You're staring at a Stripe Connect integration or a multi-tenant RBAC system that needs to be right the first time.
- You want full-stack execution plus architectural judgment — not a body-shop.
- You're a federal agency or a prime contractor with a software-heavy need (see [`government-contracting.md`](government-contracting.md)).

## When we say no (or refer)

- "Rewrite it in framework X" for no technical reason.
- Pure design-system work without software in the loop.
- Very short-term hourly staffing; we're not a staffing agency.
